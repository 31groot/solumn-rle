# ACC-212: Group inheritance is ignored when evaluating access

- **Reporter:** Ines Duarte
- **Assignee:** Priya Nair
- **Status:** In progress
- **Component:** access/policy.py

## Description

Groups can inherit from parent groups through `parents` in `data/acl.json`, and the README says
members get the roles of every ancestor group. `policy.effective_roles` only looks at the
groups a user is listed in directly, so anything granted further up the tree is missing.

## Repro

```
$ python -m access.cli check anika.s repo:read
DENY anika.s repo:read
```

Expected `ALLOW`: anika.s is in `data-eng`, which inherits `eng` (developer) and `staff` (viewer).

```
$ python -m access.cli roles ylopez
support-agent
```

Expected `support-agent, viewer` (`support` inherits `staff`).

`tests/test_policy.py::test_inherits_parent_group_roles` covers both and fails today.
